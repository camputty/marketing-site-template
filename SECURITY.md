# Security

Do not report vulnerabilities through public issues. Use GitHub private vulnerability reporting when it is enabled; otherwise contact the repository owner through the private channel documented by the deployed project, with reproduction steps, affected versions, and expected impact.

Template adopters must configure one of those private channels before production launch.

Keep framework and runtime security patches current through deliberate reviewed updates. Never commit Cloudflare, Vercel, GitHub, IndexNow, form-provider, or CRM credentials. Use least-privilege access and rotate credentials after suspected exposure.
